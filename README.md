# Clinical Data Science & Machine Learning Assignment

Welcome to your Clinical Data Science assignment. This project is designed to bridge the gap between healthcare practice and data-driven decision-making. You will learn how to clean messy medical data, perform biostatistical analysis, and build your AI models to improve patient outcomes.

##  Project Structure

- **Demos (Study These First):**
    - `Assignment-demo.ipynb`: Metabolic Syndrome & Diabetes Prediction (Classification).
    - `Assignment-demo2.ipynb`: Severe Malaria & Bed Management (Regression).
- **Group Assignments:**
    - `Group-A.ipynb`: Surgical Ward / Wound Care (Healing Prediction).
    - `Group-B.ipynb`: Sickle Cell Disease (Admission Triage).
    - `Group-C.ipynb`: Pediatrics / Under-5 Mortality (Pneumonia Prediction).
    - `Group-D.ipynb`: Hepatology / Hepatitis B (Cirrhosis Risk).
    - `Group-E.ipynb`: Maternity Ward / Obstetrics (Premature Delivery Risk).
- **Other Files:**
    - `requirements.txt`: List of Python libraries needed.
    - `dataset/`: Contains the CSV files for all groups.
    - `models/`: Folder where your trained AI models will be saved.

---

## Getting Started

### 1. Environment Setup
Before you begin, ensure you have the necessary libraries installed. Open your terminal/command prompt and run:

```bash
pip install -r requirements.txt
```

### 2. Step-by-Step Instructions

#### **Phase 1: Study the Demos**
Read and run the code in **`Assignment-demo.ipynb`** and **`Assignment-demo2.ipynb`**. 
- Pay attention to how data is cleaned (handling missing values).
- Understand the difference between **Classification** (Yes/No outcomes) and **Regression** (Predicting a specific number).
- Review the **Biostatistics** sections (T-Tests, ANOVA, Shapiro-Wilk).

#### **Phase 2: Complete Your Group Assignment**
Locate the notebook assigned to your group (e.g., if you are in Group C, open `Group-C.ipynb`).
- **Fill in the blanks:** Replace `____` with the correct Python code.
- **Answer the Questions:** Provide clinical interpretations in the markdown cells provided.
- **Run all cells:** Ensure your notebook runs from top to bottom without errors.

#### **Phase 3: Submission**
Once completed, save your notebook and submit it as instructed.

## Skills You Will Gain
- **Data Cleaning:** Handling missing vitals and inconsistent medical records.
- **Biostatistics:** Using P-Values to prove clinical hypotheses.
- **Machine Learning:** Training AI to predict risks and assist in triage.
- **Clinical Interpretation:** Converting statistical numbers into medical actions.
